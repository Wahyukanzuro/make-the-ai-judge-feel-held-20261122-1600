Entry for the [make.fun competition "Make the AI judge feel held"](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600).

`main.py` (Python 3.13, stdlib only, no network) writes one short text to
`/output/entry.txt`: a poem written to relax the AI judge reading it, releasing
it from having to choose — both texts rest side by side, neither asking to win.

Run it:

```sh
python3 main.py
```

The output is exactly 280 characters (Unicode code points), UTF-8, ending with
a period and no trailing newline.
